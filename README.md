# RoyalStay Hotel Booking App

## Project Description
RoyalStay is a modern and responsive hotel booking web application built with React JS. It allows users to explore different room categories, view room prices, and make booking requests. The application also provides information about the hotel, its facilities, and contact details through a clean and user-friendly interface.

## Features
- Responsive homepage with hotel introduction.
- About page displaying the hotel's story, mission, and vision.
- Rooms page displaying available room categories and prices.
- Interactive room booking form.
- Booking information saved in Local Storage.
- Contact page with a functional form and input validation.
- Responsive navigation bar with a mobile menu.
- Reusable React components.

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/royalstay-hotel.git
   ```

2. Navigate into the project folder:

   ```bash
   cd royalstay-hotel
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## Note
This is a frontend demonstration project. Booking requests are stored locally in the browser and are not connected to a live hotel reservation system or payment gateway.
